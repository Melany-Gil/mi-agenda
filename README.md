# Mi Agenda

Gestor de tareas diarias: tablero Ayer · Hoy · Mañana, calendario, reloj, responsables,
tareas urgentes, bitácora del día y recordatorios con notificaciones.

## Publicar en GitHub Pages
1. Crea un repositorio (por ejemplo `mi-agenda`) y sube **todos** estos archivos a la raíz.
2. En el repositorio: **Settings › Pages › Build and deployment**: *Deploy from a branch*, rama `main`, carpeta `/ (root)` › **Save**.
3. Espera 1–2 minutos y abre `https://TU-USUARIO.github.io/mi-agenda/`.
4. En la agenda, pulsa **Activar notificaciones** y elige *Permitir*.
5. Opcional: menú ⋮ › **Instalar como aplicación** para tenerla en su propia ventana.

## Importante
- Las tareas se guardan **en el navegador de cada equipo** (no en GitHub). Nadie más las ve,
  pero tampoco se sincronizan entre equipos: usa ⋮ › Exportar / Importar copia.
- Los recordatorios funcionan mientras la agenda esté abierta (puede estar minimizada).
